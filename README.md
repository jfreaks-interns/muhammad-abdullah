# About the Project - Event Booking API

A REST API for an event booking platform. Users sign up, create events with a limited number of seats, and book seats on other users' events. When an event is full, new bookings join a waitlist, and when someone cancels, the first person on the waitlist gets the seat.

There is no frontend. Everything is used and tested through Postman.

**Stack:** Node.js, Express 5, MongoDB with Mongoose

**Scope**
- Week 1: events API (create, view, update, delete, list upcoming events)
- Week 2: user accounts with login, seat booking, cancellation and the waitlist
